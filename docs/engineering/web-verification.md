# Web 实现与验收

用于本轮涉及异步表单、构建失败或浏览器验证的工作，按实际改动读取对应部分。沿现有工程和工具能力实施，不增加业务功能或改变已确认页面来满足检查。

## 异步接口与调用方

表单从同步保存改为异步保存时，一并核组件 props、所有调用方和失败处理。声明返回 Promise 且调用方需要 await 的回调，应返回原 Promise；不能用 `void handleSubmit(...)` 丢掉返回值。原本明确不等待结果的事件处理不强制改成另一种协议。

由一个明确的层处理失败：向上抛出后由调用方接住，或返回可辨认的成功/失败结果；不能吞掉异常后让外层把 Promise resolve 当作保存成功。等待期间按产品设计防重复提交，finally 释放等待状态；输入/所选文件何时清理由真实业务结果决定，失败保留，迟到结果不能覆盖新一轮输入。

先运行与改动相关的现有类型检查/构建，使用项目绑定的公共入口和原镜像。接口改变时优先核所有引用，不凭一个编译错误猜另一组件的类型问题。

## 构建与首个错误

沿项目绑定和已有进度恢复确切命令，不反复搜索脚本位置。构建失败先读 `.ai-coding/command.json` 指向的本轮日志，或当前执行入口保留的脱敏 stdout/stderr；确认源码位置、镜像、命令与时间属于本次运行。

先定位首个具体源码错误及其文件/行号，再读附近实现和接口调用方。外层 throw、日志截断和浏览器快照截断只是定位线索，不是业务根因。需要更多输出时读取已保存结果，不能为取日志重新触发构建、部署或写操作。修复后重跑受影响检查；只有输入与产物证据仍匹配时复用已通过结果。

命令计时在实际结束/失败路径也要保存：已有入口的事件直接引用，额外计时使用 finally 收尾。不把最后一次成功构建的秒数当作包含失败、修复、发布和验收的总时长。

## 浏览器操作与定位

先读当前工具 schema，确认目标页面/标签、URL 和最新快照。元素 ref 与页面和快照绑定；导航、弹窗变化或切页后重新定位，不沿用另一页的 ref。只有工具确实支持的参数才传入，不能从别的工具类推 viewId、selector 或调用参数位置。

填表、点击和文件选择优先使用支持的原生交互。填完后核当前目标页的实际值，再通过正常提交和业务结果验证受控组件状态，不把“工具返回成功”或 DOM 有字当持久化成功。密码快照隐藏值不能证明密码保留或清空；需要此项验证时只观察非秘密布尔结果/长度，不能回显内容。

上传先定位真实 file input 或与其关联的 label/选择按钮，按工具支持的文件设置或 chooser 流程操作。隐藏 input 未出现在快照中不等于产品不能上传；工具不支持时记录限制并改用已支持的路线，不能编造 ref、改 DOM 解除隐藏或注入文件来报告原页面体验通过。

只读脚本用于观察，不代替真实填表、提交和上传；是否允许表达式、函数体或其他形式以当前工具契约为准。脚本 undefined、解析失败或未取到字段时，先用最小只读表达式核目标和返回格式，不直接推断应用失败或工具参数无效。同一路径两三次无新证据就停止重复。不得把日志中的 IIFE、转义或 viewId 推测写成通用平台根因。

用户名/按钮未显示先查当前视口、响应式样式和可见性；DOM 存在但被设计隐藏不等于登录失败，缺少一个显示值也不等于用户身份异常。诊断与业务验收各自留证。

## 验收证据与结论

同一浏览器 profile 的两个标签通常共享会话。验证独立会话时，先确认实际使用了隔离的 profile/context 或普通与无痕窗口，并分别建立所需登录态；不同页面 ID、第二页自动登录或清空同一页存储都不证明两套会话隔离。工具没有隔离能力时只能报告同会话多页面结果，独立会话仍待验证。

按本轮要求分别验证登录失败、业务写入失败和文件上传失败；一个失败场景通过不替代其他场景。对保存/上传失败，检查错误反馈、输入及所选文件、等待状态恢复、云端实际结果和恢复后的唯一结果。模拟按钮仅证明对应模拟分支，不替代实际请求失败/结果未知后的恢复。使用工具支持的受控断网或请求阻断，不为测试改生产权限、全局代理或破坏共享资源。

断言使用本轮确切记录/对象标识、目标组件和真实操作结果，不能只搜索页面是否含“失败”或旧提示。未观察到的错误提示、文件保留、实际失败重试及独立会话保持未验证；不要先报告“全部通过”再把明确要求改为可选。本人接管仅代表开始试用，不代表已反馈通过；更新同一进度区块，保留一个明确的下一动作。
