# 本人与助手分工

本人决定需求、原型、费用、账号授权和保存位置，并亲自试用网页与手机。助手负责目录/文件版本、配置、依赖、构建、发布、调用核验、受控失败测试和脱敏记录，不让本人写技术 spec、审日志或勾选助手状态。

必要本人操作一次一个动作；完成后接续已授权任务。普通内部步骤不变成审批关卡。未观察或未试用的项目明确未验证；网页勾选只记录本人操作。

检查顺序：当前通用阶段门槛 + 所选案例补充 + 当前任务专项门槛。Android 专项交 ai-coding-android。阶段结果写在项目内，不向本人追加长技术提示。案例预计耗时仅适用于案例，记录实际墙钟和本人等待。


## 2.1 AI 本人操作

AI平台注册、领取当前可用优惠、充值决定、创建自己的Key并在程序设置中填写、选择模型和试用由本人完成；助手负责保护后端、连接核验和故障处理。环境准备不检查模型账号，P-01只建本地基础，首次AI需求才落默认文件和设置路线，V4按ai-service-setup.md接入；不让本人排查技术日志，也不由助手代填Key来替代本人操作。


本人选择优惠/充值（可跳过），首次在程序设置填写自己的模型Key并选模型；已有配置复用。助手落实项目指定配置用户、私有后端身份、加密/CAS/限额与技术测试。项目已明确授权的用户可编辑设置，不新增另建管理员作业。
