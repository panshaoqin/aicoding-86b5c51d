# 阶段执行、验证复用与可接续记录

按当前阶段读取，不把整套资料每轮重新加载。A保存原始准备，用户级索引发现，B保存项目事实；从实际preparationId恢复，不猜默认目录。

新会话尚无当前检查或排障时用环境 Skill/scripts/Test-CourseReadiness.ps1 -ProjectDirectory <B> 一次核当前绑定、引擎/镜像和依赖；失败返回下一Skill/动作。依赖或Node版本错误先核执行位置，调用 Invoke-CourseProject -Action Repair，不能宿主安装或关engine约束。标准命令刚完成当前检查时直接接续，避免重复预检。所有项目脚本用 RunScript；构建、发布、Android继续既有入口。

调用环境 scripts/Update-CourseProgress.ps1 -ProjectDirectory <B> -Stage <本轮标识> -Objective <本轮目标> -NextAction <下一动作> 开始记录并定位具名Spec。重新开始同名阶段用 -NewRun；本人试用等待沿同一轮继续计时。新建Spec只填事实和目标，由助手按模板补本轮有序步骤/恢复，不能把初建文档当方案已完成。方案记录决定，镜像/依赖/产物事实引用脚本证据，避免手抄大报告。

长等待按 -Status waiting -WaitKind download|migration|deployment|model|learner|diagnosis 记录原因；完成动作后接续同阶段。技术完成用 -Status verified -EvidencePath <B内实际结果>；本人/手机未试用 learner-pending。该记录是接续，不代替证据内容核验。当前状态在 .ai-coding/progress.json，追加历史在 .local/course-execution.jsonl，不覆写用户的进度备注。

## 复用与失效

已有准备、镜像、健康容器与Linux卷直接复用；包清单/锁文件未变不重装。源码、依赖、镜像、服务绑定、授权、产物或版本变化时只重验受影响范围；不能以缓存跳过当前引擎/挂载、授权、正式网址内容或真实会话权限核验。更换Key/模型也要验证实际配置与路由；模型配置变化不自动重打APK。旧通过和本次失败分别保存。

版本适配先读实际锁文件与工程实现。PG schema、图片签名URL返回字段、CAS更新返回行和CLI参数使用已验证方法；从当前官方接口核差异，普通修复不升级主版本。发布先固定真实dist/资源清单，云端Updating时查原任务终态，不反复提交。Pages沿Publish-Pages.ps1及Recover，CloudBase沿已验证官方路线和Publish-CloudBase产物检查。

## 稳定浏览器验证

按项目Spec区分请求已接收、处理中、已完成、失败与结果未知，明确各自可验证的依据。同步保存、后台保存或乐观更新由本项目设计决定；界面反馈与实际状态一致，不把请求受理或临时展示误报为已持久完成。按所选方式实现失败恢复、重试和结果查证，再验证相关成功/失败路径；不统一要求等待后关闭界面，不向未采用的存储机制添加事务规则。

按当前可见容器和语义控件定位；涉及动画、浮层或重叠元素时，检查可见状态、遮挡和可操作条件，使用正常用户操作验证。程序化触发或强制点击可辅助诊断，不能单独证明用户可操作；等待动画结束或控件可操作合理，不能靠任意增加固定等待时间掩盖问题。提示文案与业务结果分别核验，不能只看提示就认定完成。具体状态、选择器与交互修复由项目Spec和源码维护。

失败保存截图、当前状态和首个错误，修后先跑相关用例；验收范围取自项目Spec。会话恢复、独立会话、多用户隔离和管理操作提供不同证据，不能互相替代；未要求的功能记不适用，不能增加功能来凑齐通用清单。

测试存储前检查应用启动、后台同步和迁移是否会自动上传测试数据；采用独立测试上下文并隔离这些副作用。记录本轮确切ID/归属，清理前预览；共享环境中总行数变化不等于本轮创建，不根据数量或标题猜测删除对象。

## 时间与等待

读assets/course-timing.json报告首次/复用及迁移范围。入口自动记录命令真实起止/耗时，包括预检失败；阶段时间使用真实时钟，不手填未来时间、不用日志字数或文件mtime推算。下载/搬盘/平台/本人等待与排障分开；并发窗口不重复累计。相同条件2—3次无新证据停止重复尝试，转最小探针并保存排除项，继续独立工作。阶段结束/会话中断更新Spec、current及下一动作，不能因超时降低权限或省验收。
